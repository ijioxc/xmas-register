# 報名系統：接上 Google 試算表

```
register.html（報名頁） ──POST──▶ Apps Script（Code.gs） ──寫一列──▶ Google 試算表「報名」分頁
```

## 一次性設定（約 10 分鐘，要用你的 Google 帳號操作）

1. 開一份新的 Google 試算表，取名「愛理不理 報名名單」
2. 上方選單 **擴充功能 → Apps Script**
3. 把左邊 `Code.gs` 的內容全部刪掉，貼上本資料夾的 `Code.gs`，按儲存（💾）
4. 上方函式選單選 **setup** → 按 **執行**
   - 第一次會跳出「需要授權」→ 選你的帳號 → 「進階」→「前往（不安全）」→ 允許
   - 這是 Google 對所有自己寫的腳本都會顯示的警告，不是病毒
   - 回到試算表，會多一個「報名」分頁，有標題列
5. 右上角 **部署 → 新增部署作業**
   - 類型（齒輪）選 **網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按部署，複製「網頁應用程式網址」（結尾是 `/exec`）
6. 把網址貼給 Claude，會填進 `register.html` 的 `SUBMIT_URL`

## 確認有通

- 用瀏覽器打開那個 `/exec` 網址，看到 `{"ok":true,"msg":"報名收件程式運作中","v":3}` 就是成功（沒有 `"v":3` = 跑的還是舊版）
- 不要再執行 setup：舊版 setup 會在 1000 列放空勾選框，序號會亂掉
- 測試：打開 `register.html?api=你的exec網址`，報名一次，試算表會多一列

## 之後修改 Code.gs

改完要 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，網址不會變。
只按儲存不會生效。

## 試算表欄位

| 序號 | 報名時間 | 系所 | 身分 | 應繳 | 學號 | 姓名 | 飲食 | 已繳費 ☐ | 備註 |
|---|---|---|---|---|---|---|---|---|---|

- 名單自動依系所排列：每筆新報名、每次打開試算表都會重排（最右邊隱藏一欄「系所順序」是排序用的，不要刪）
- 以前的資料要一次排好：上方選單 **報名工具 → 依系所重新排列**（第一次會要授權）
- 「飲食」欄：葷食／素食／有忌口：說明（v7 起；舊表第一次收到報名時自動插入這一欄）

- 收到錢 → 在「已繳費」打勾
- 要匯出：檔案 → 下載 → Excel 或 CSV
- 要看各系人數：選取資料 → 插入 → 資料透視表，列放「系所」，值放「學號（COUNTA）」

## 程式會自動擋掉

- 同一個學號報第二次（會告訴對方原本的序號）
- 12/14 23:59 之後的報名（時間在 `Code.gs` 最上面的 `DEADLINE` 改）
- 系所不在名單、學號格式不對、沒填姓名
- 機器人亂填（隱藏欄位）
- 金額以程式裡的 `FEES` 為準，網頁傳什麼數字都不採用
